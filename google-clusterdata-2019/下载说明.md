# Google ClusterData2019 本地范围

来源为 Google 官方 cluster-data 仓库和 clusterdata_2019_a 至 h 公开存储桶，许可 CC BY 4.0。机器事件和属性原文件及此前单个 JSON 使用样本保留。本轮另完整遍历 a 集群 12,085 个 Parquet 使用对象的必要列，原对象共 437,603,169,723 字节，保留列范围及少量间隙共 91,034,835,113 字节（84.78 GiB）。不包含八集群使用表全部列，不是全五表数据集。

column_cache/a 保留原始压缩列字节；projected_usage/a 保存逐对象聚合与哈希证据；aggregated/complete_usage_a_15min.npz 为完整 a 集群必要列聚合，cella_complete_usage_15min.csv 为五域 14,880 行。任务层 JOB 聚合排除 ALLOC_SET，CPU 为 NCU，内存为归一化 RAM，功率为利用率，没有实际 kW/MW。原 .parquet.gz 对象为 PAR1 Parquet，没有外层 gzip。原对象 MD5 只与官方清单和返回的 HTTP 头比对，未下载全列后独立重算；保存字节均有 SHA256，实际复核范围见 results/complete_projection_audit.json。

全部新增特征只用历史，未来负载由模型预测。完整导出仍可能遗漏物理任务与 alloc 开销，也未独立做全任务键去重。预测和冻结结论见上一级最新 Word 汇报。没有提交 BigQuery 或付费云任务。旧 JSON 样本不具有已知入选概率，不能替代本轮完整 a 聚合。
