# 复现范围

## 可以直接完成的部分

`python scripts/review_results.py`只用标准库读取聚合指标，并检查Google当前值和NLR表行数。各轮模型、损失、时间边界和采用理由可从源码及协议查看；报告文字和比较表无需下载数据即可阅读。

## 重新训练与推理

本仓库是研究源码和结果档案，不是包含训练数据、检查点及预测缓存的完整部署镜像。完整重跑需另外取得同版官方数据、预训练权重、指定依赖，并重新构建本地处理数组和缓存。海光寺私有原表不随仓库提供，无法仅凭此仓库复现该案例。

第三方代码只作固定版本引用：

```console
git submodule update --init --recursive
```

HDSF参考固定于`648777507ebc57e7498ce61f4ae2236ab179e6a8`；Moirai2使用的uni2ts来源固定于`cfd46d4510ed8896f263116f32928eede05b0a75`。Granite依赖提交及来源见`UPSTREAM_SOURCES.json`。TinyTimeMixer旧实验使用的`ttm_official`是官方模块的本地适配导入位置，需要按原准备脚本及指定Granite版本重新准备，没有将第三方包副本提交。

`requirements-research-cpu.txt`记录HDSF原研究依赖，`experiment/requirements-lock.txt`记录早期GPU环境版本；两者是不同环境，不应直接合并安装。CPU、GPU、不同模型版本具有兼容约束，历史源码中的环境路径不会因Git克隆自动创建。

## 冻结与哈希

公开副本移除了个人路径，并将本地根目录替换为`${PROJECT_ROOT}`、用户目录替换为`${USER_HOME}`。文档中的旧本地链接可能指向未发布的缓存、原始数据或Word，不代表这些文件已上传。

因此，历史`protocol.sha256`、`selection.sha256`及嵌套绑定仍描述原研究字节；经公开脱敏的文件不一定与之逐字一致。原始和公开文件哈希记录在`PUBLICATION_PROVENANCE.json`，不把脱敏副本标为原冻结文件。不能删除哈希断言强行称作原实验复现；重新实验应使用新的输出目录、生成新的协议/来源绑定并在评分前冻结，保留原档案。

临时开发检查点曾按项目整理要求删除，最终状态、来源和分数保留本地；公开仓库不提供任何神经权重或二进制模型。源码中引用这些文件的旧审核程序描述其历史检查范围，不意味着在无数据仓库中可直接通过全部历史检查。

Google同一月份已被多轮查看，NLR测试时段也已暴露，预训练语料重叠尚不明确。重新执行不能把它们变成独立盲测。80%经验区间也不提供跨场站覆盖保证。
