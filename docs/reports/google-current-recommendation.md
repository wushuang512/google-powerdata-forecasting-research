HDSF是 Half Day Simplex Fusion：按12小时区间拟合非负且和为1的成员权重。24小时成员池包括Amazon Chronos-2、NX-AI TiRex-2、Google TimesFM2.5、Datadog Toto2.0 313M、Google TimesFM3及本地LightGBM与滞后回归。7天成员为TimesFM3、Toto2.0、IBM Granite PatchTST-FM-r2及历史水平与日内形状平滑。部分成员权重为0，成员池中出现不代表实际贡献。

24小时新校正把PatchTST微调前后的预测差分分成每天均值和去均值的形状，只保留均值部分。因此整天上移或下移，主要修正水平偏差，不直接重塑峰值位置。7天只保留零均值部分，尽量维持原HDSF优秀的每日均值；这是日均几乎完全不变的直接原因。

基础HDSF的开发权重与测试权重分别用D14和D22前可得信息拟合；新校正和筛选均只使用相应起报前的历史。修正后限制在[0,1]，仅与利用率目标范围一致，不表示物理电量守恒。

改进来自哪里及为何仍然有限

HDSF最初超过旧方案的主要原因，是不同半日采用不同专家。24小时约86.52%的改善发生在后半天，原Chronos和Toto承担前半天，TimesFM3的不同模式承担后半天。同一成员池的固定消融支持分段优于等权和整段共享权重；属于事后机制解释，不能据此重新挑测试权重。

7天优势主要在平均水平。此前固定分析中日均水平MSE下降6.35%，形状MSE反而上升1.14%；历史水平与日型平滑平均占29.01%权重，去掉会使日均变差。主要专家残差相关约0.93至0.96，互补空间有限。这也解释了曲线WAPE不一定同步领先。

所有评价指标的统一计算定义

| 指标 | 计算规则 |
| --- | --- |
| 曲线WAPE | 每PDU有效点绝对误差和除以该PDU实际绝对值和，乘100%，再对57域等权平均。不是池化所有点后计算。 |
| 每日均值WAPE | 预测和真值都取完整96点均值；排除任意无效点的整日目标，然后先PDU计算再等权平均。 |
| MAE 和 RMSE | 全部有效点池化，分别求绝对误差均值、均方误差平方根。每日均值版本只用完整有效PDU日。 |
| P95 APE | 所有有效点的绝对百分比误差第95百分位；APE为绝对误差除以实际绝对值乘100%。 |
| 2% 与 5%命中 | 有效点中APE≤2%或≤5%的比例；日均版本按完整有效PDU日同样计算。 |
| 每日最大值MAPE | 有有效数据的PDU日内，对有效槽分别求预测和真实最大值，然后平均最大值APE。 |
| 峰时误差 | 有效槽中的首个最大值位置差的绝对值乘15分钟，跨PDU日平均；不做24小时循环距离。平台或平峰下敏感。 |
| 全局绝对偏差 | 100%乘全部有效点有符号误差和的绝对值，除以实际绝对值和。不是绝对误差均值。 |
| 分域WAPE | cell-a的5域与其余52域各按域WAPE等权平均，不把CPU换算成kW。 |
| 误差减少率 | 100%乘1减模型WAPE除以同任务朴素基线WAPE；日均与曲线用各自基线。 |
| 改善数量 | 分别数有多少PDU、cell及起报在WAPE上优于对应朴素基线。 |
| 覆盖率 宽度 Winkler80 | 真值在区间内的有效点比例；上界减下界的均值；80%区间宽度加出界距离的10倍罚项。越窄不是单独最优。 |

9月28日原材料明确写明Google先对每条供电域分别计算WAPE，再对57条取平均。源项目公布的池化曲线分数不直接与本报告比较。历史仅有效槽均值WAPE另作诊断附表，主排名始终使用完整96点日均。
