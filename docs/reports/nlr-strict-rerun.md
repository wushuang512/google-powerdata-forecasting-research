选模冻结与科学性边界

验证交叉检验分三次向前留出，融合拟合只用更早的验证日期；7天标签越过留出起点的样本剔除。每折LightGBM配置也只在此前验证日期选择。随后按选定比例拟合全部验证融合权重，在测试前同时冻结两个预测时距。

| 任务 | 半日分支比例 | 融合样本内MAPE % | 融合样本内WAPE % |
| --- | --- | --- | --- |
| 1天 | 0 | 6.3273 | 4.7385 |
| 7天 | 0.5000 | 9.3637 | 7.4728 |

半日分支比例由向前验证选择：24小时为0，7天为0.5000。比例为0表示实际退回全局单纯形，不能归因于12小时分段。融合样本内分数使用拟合过的标签，只作诊断。

这套协议科学之处是时间顺序、因果输入、共享评价窗口、分层处理融合选模及冻结配置。其限制是：源时区未验证，严格缺测筛选只评价可用日期；已查看的2023至2025区间和未知基础模型预训练语料重叠，使此次不能称为新的严格盲测。全部十四个方案本轮都在首次测试推理之前登记并冻结；这不会消除之前看过同一测试时期的事实。

如果最终研究重点是曲线WAPE领先，应在下一份尚未评分的新协议中预先指定WAPE主选模、MAPE辅助约束。当前已冻结的MAPE规则保持不变，避免看过测试成绩后换目标。时间交叉验证原则见文末资料。

原始字段与处理边界

| 字段 | 含义与处理 |
| --- | --- |
| ts | 原始时间戳无时区。临时按UTC解释，质量报告保留timezone_verified false；不能据此证明真实UTC或当地自然日。 |
| it_power_kw | 数据中心IT设备功率，kW。可另建IT功率预测协议，本轮未运行；实际目标是五项派生汇总。 |
| cooling_kw | 室外冷却设备风机和伴热等功率，包含专用过滤泵的冷却负荷记录。 |
| hvac_kw | 暖通设备功率，包括电气房间相关风机及补风机组。 |
| plug_and_light_kw | 照明与插座，以及相关辅助负荷，kW。 |
| pump_kw | 数据中心及冷却水循环泵等功率，kW。按记录值处理，不另外添加2.67kW。 |
| outdoor_air_temp | 本地实际天气字段；官方说明为华氏度，先换算C=(F−32)×5/9再聚合。 |
| outdoor_air_humidity | 相对湿度百分比；不把百分数误当0至1比例。 |
| facility_power_kw | 五项各自区间均值的派生合计；任何一项区间均值缺失则缺失，不是直接测量的设施总功率。 |

先删除配置日期范围外记录，包括天气1970年时间。固定宽泛过滤范围为单项功率0至20000kW、温度−70至60摄氏度、湿度0至100%；这些是本轮提前设置的质量界限，不是已核实的设施额定容量。重复时间戳取均值，再按左闭右开15分钟区间取有限记录均值，时间标注区间起点。

有效区间不要求15条分钟记录都齐全，原始有限记录数单独保存。只对历史协变量最多前向填充4格；目标及历史目标不填充，无后向填充或双向插值。第一和最后完整96格目标日确定边界，内部缺测日期保留在时间轴。
