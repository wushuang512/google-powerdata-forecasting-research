# 从这里开始

最新报告：**Google PowerData 2019 持续探索与精度改进汇报.docx**。
前两轮 Word 是过程记录，结论以最新报告为准。

## 当前结论

次日曲线：旧组合 2.4165%，新固定组合 **2.3848%**，相对下降 **1.31%**。新组合为 25% Chronos-2 单变量 + 25% TiRex-2 单变量 + 50% TimesFM 3.0 集群与历史生产特征；对最终利用率裁剪到 [0,1]。这是第三轮预先冻结的次要方案，事后表现最好；第三轮主方案为 2.3914%。第四轮保守选择保持该组合，新增微调没有获得可靠额外收益。

结论是“小幅探索性改进”，不是“显著突破”或“保证不发生过拟合”。联合日期块与集群重采样的 95% 改进区间为 [-0.0211, 0.1068] 个百分点，跨零。一个月数据已被多轮查看，必须用新月份确认。模型预训练是否接触该公开数据也未排除。

七天曲线：TiRex-2 **2.8803%**，新组合 2.9032%，所以七天优先保留 TiRex-2。新组合峰值 MAPE 2.0687%，仍不如前一天同刻 1.0682%；不能宣称全面领先。

## 双击运行

1. `01_研究用新组合_预测次日.cmd`：本月次日最优探索性方案，仅作本地非商业研究。
2. `02_TiRex_预测七天.cmd`：目前七天曲线较优方案。
3. `03_旧组合_预测次日.cmd`：保留旧等权基线用于比较。
4. `04_第二轮峰值方案_预测次日.cmd`：同时输出曲线和峰值修正版本。
5. `05_新组合七天对照.cmd`：新组合七天外推，对照用途。

默认输入截至 **2019-05-31**，示例输出是 **2019-06-01** 起的利用率，绝不是今天负荷；本数据没有六月真值，不能评价这些示例的精度。新组合结果在 `experiment/round4/results/deployment_origin31_1day.csv` 和 `deployment_origin31_7day.csv`；TiRex 在 `experiment/round2/results/tirex_deployment_origin31_7day.csv`。

本机 Python、依赖、数据、权重都在此目录，无需再次下载模型。新组合目前使用本机 CUDA，TiRex 使用官方 CPU 实现；运行中请保留窗口。文件夹包含本机绝对路径，不是可随意改名或跨机器拷贝的免安装软件。输入程序针对 57 域、31 天结构，不可直接替换成不同数据后假定可用。
