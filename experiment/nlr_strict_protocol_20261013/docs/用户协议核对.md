# 本轮用户协议逐项登记

用户要求严格按已经提供的完整NLR数据口径与实验协议，重新跑各个模型并单独评估汇报。

- ts、outdoor_air_temp、outdoor_air_humidity实际字段；华氏转摄氏，湿度百分数。
- 默认facility_power_kw为五项各自15分钟有限样本均值的派生合计，任一分项无有效均值即缺失。不是设施直接总表。
- 无时区原始钟，临时UTC，timezone_verified false。本轮不修改未知时区。
- 固定范围屏蔽异常、删除范围外1970记录、重复时间均值、15分钟左闭右开并标起点；历史最多到t减15分钟。
- 仅历史协变量前填最多4格，目标及历史目标不填；跳过缺失窗口并报告。
- 有效区间不要求15条分钟全齐；覆盖计数另存。首尾完整96格目标日确定边界，内部缺测保留。
- 连续日历约60/20/20，验证至少8天、测试至少9天；完整标签留在所属划分。
- 统一14天1344点。需训练的模型初拟合只用训练，按冻结配置重拟合训练加验证；基础模型原权重固定，缩放也按训练和训练加验证分别拟合。
- LightGBM参数按全验证起报平均MAPE选择；HDSF半日比例及总体方案使用共同的向前验证交叉检验起报MAPE，各融合样本内分数单列。
- 全部十四方案在本轮首次测试之前共同冻结。每日滚动，测试只更新已观测历史，不重新拟合；七天重叠并另导固定日历七天非重叠。
- 未来协变量只有已知日历，不输入未来真实负荷或天气。
- MAPE阈值1e-8，起报等权，排除计数、全零null；WAPE百分数和RMSE原单位；每天先聚合96点再评分；报告相对固定基线误差降低。
- 完整CSV及Python表格同时导出，不称100减WAPE为准确率。

附加公开设置：五个主要方案、三条基线和六个历史Google推荐一开始全部登记。旧方案为冻结源权重迁移，历史统一14天，部分7天分支是预先指定扩展；不声称所有神经权重在NLR重新训练。仅facility_power_kw，本轮不运行可选IT标签。原始ts没有经官方确认的时区，正式部署还需核实。

所有本轮预测从空白新缓存重新产生。既有测试时间段已经被查看，这是一轮按协议重复评估，不会因为重跑而成为新的独立盲测。
